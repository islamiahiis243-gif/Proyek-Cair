# Proyek Cair WebApp

Aplikasi manajemen operasional proyek konstruksi (Proyek Cair). Didesain sederhana, ramah pengguna (*user-friendly*), mendukung mode Terang/Gelap (*Light/Dark*), dan menggunakan Bahasa Indonesia 100%.

## Fitur Utama

- **Antarmuka Pengguna Intuitif & Cepat**: Desain modern berbasis Tailwind CSS dengan dukungan tema Terang / Gelap.
- **Manajemen Dokumen & Verifikasi QR**: Pembuatan dokumen resmi, penandatanganan elektronik, dan verifikasi integritas berkas.
- **Kontrol Proyek & Arus Kas**: Pemantauan anggaran biaya (BOQ), pencatatan material/inventaris, dan arus kas proyek.
- **Multi-Tenant / Proyek Klien**: Dukungan struktur tenant dan data proyek (seperti CV Menara Megah).

## Menjalankan Aplikasi

```bash
# Pasang dependensi
npm install

# Jalankan server pengembangan
npm run dev

# Build untuk produksi
npm run build
```
